## Аннотация

В данной статье представлена информация о алгоритмах компьютерного зрения, которое используется в сельском хозяйстве для обработки и интерпретации визуальной информации. Технология позволяет машинам распознавать закономерности, формы и цвета, уникальные для каждого типа сельскохозяйственной культуры.

**Цель работы** — сравнительный анализ эффективности различных алгоритмов машинного обучения для решения задачи бинарной классификации изображений листьев томата (здоров / фитофтороз) и обоснование выбора оптимальной модели для последующей интеграции в агропромышленные комплексы (АПК).

**Результат** — выбор оптимальной модели для разработки программного обеспечения, специализирующегося на распознавании фитофтороза у томатов.

**Ключевые слова:** машинное обучение, XGBoost, случайный лес, свёрточные нейронные сети, классификация изображений, фитофтороз томата.

---

## Алгоритмы машинного обучения

Для решения задачи бинарной классификации были отобраны четыре алгоритма, представляющие различные подходы:

### 1. SVM + HOG (Метод опорных векторов)
- **Тип:** классический ML
- **Принцип:** извлечение признаков HOG + линейное разделение гиперплоскостью
- **Роль:** базовый уровень сравнения (baseline)
- **Преимущества:** интерпретируемость, низкие требования к данным

### 2. Random Forest (Случайный лес)
- **Тип:** ансамбль деревьев
- **Принцип:** усреднение результатов множества деревьев, построенных на разных подвыборках
- **Роль:** скрининг с требованием 100% обнаружения
- **Преимущества:** высокая скорость, устойчивость к переобучению

### 3. XGBoost (Градиентный бустинг)
- **Тип:** градиентный бустинг
- **Принцип:** последовательное обучение деревьев с исправлением ошибок предыдущих
- **Роль:** оптимальный баланс точности и скорости для мобильных АПК
- **Преимущества:** высокая точность, интерпретируемость, компактность

### 4. CNN (Свёрточная нейронная сеть)
- **Тип:** глубокое обучение
- **Принцип:** автоматическое иерархическое извлечение признаков через сверточные слои
- **Роль:** задачи, требующие максимальной точности без ложных тревог
- **Преимущества:** максимальная точность положительных предсказаний

##  Установка и запуск

### 1. Клонирование репозитория

```bash
git clone https://github.com/sotnikovazhanna/tomato_classification.git
cd tomato_classification
```

### 2. Создание окружения

```bash
conda create -n plant_disease python=3.9
conda activate plant_disease
```

### 3. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 4. Подготовка данных

Скачайте датасет [PlantVillage с Kaggle](https://www.kaggle.com/datasets/emmarex/plantdisease) и скопируйте папки:

- `Tomato_healthy` → `data/processed/healthy/`
- `Tomato_Late_blight` → `data/processed/late_blight/`

### 5. Запуск обучения

```bash
# Проверка загрузки данных
python src/preprocessing.py

# Обучение моделей
python src/svm_model.py
python src/random_forest_model.py
python src/xgboost_model.py
python src/custom_cnn.py

# Сравнение результатов
python src/final_comparison.py
```
